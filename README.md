# 🎓 Panduan Yudisium

Panduan interaktif untuk membantu mahasiswa menyelesaikan proses yudisium di FMIPA. Dibuat dengan antarmuka modern, responsif, dan mudah digunakan.

---

## ✨ Fitur Utama

- **📋 Checklist Interaktif** — Tandai progres persiapan berkasmu langsung di halaman
- **🗂️ Tampilan Tab** — Navigasi mudah antara daftar berkas Transkrip Asli dan Ijazah
- **🖼️ Preview Modal** — Lihat contoh folder dan penulisan MAP tanpa meninggalkan halaman
- **📥 Template Unduh** — Download langsung template penulisan MAP dan surat pernyataan (.docx)
- **🔗 Link Penting** — Akses cepat ke Bebas Pustaka Unri dan E-Form Tugas Akhir
- **📱 Responsif** — Tampilan optimal di desktop, tablet, maupun smartphone
- **💜 Desain Modern** — Glassmorphism, animasi halus, dan typography premium

## 🚀 Cara Menggunakan

1. **Download** atau **clone** repository ini
2. **Buka** `index.html` di browser apapun
3. **Ikuti** langkah-langkah dari atas ke bawah
4. **Centang** checklist saat sudah menyiapkan dokumen
5. **Download** template yang dibutuhkan

```bash
# Clone repository
git clone https://github.com/Deviantkay/list-yudisium.git

# Buka di browser
start index.html  # Windows
open index.html   # macOS
```

## 📝 Konten Panduan

### Tahapan Yudisium

1. **Setelah Kompre** — TTD Dekan & pengajuan TA
2. **Pengambilan Berita Acara** — Persiapan flashdisk & file ZIP
3. **Berkas Yudisium** — Dokumen untuk MAP Pink (Transkrip & Ijazah)
4. **Pendaftaran Portal** — Upload file ke portal yudisium & wisuda
5. **SKL** — Estimasi waktu tunggu Surat Keterangan Lulus

---

## 🎨 Kustomisasi

Untuk mengadaptasi panduan ini ke fakultas atau institusi lain:

### Mengubah Warna
Edit variabel CSS di `style.css`:
```css
:root {
  --primary: #8b5cf6;     /* Warna utama (ungu) */
  --accent: #06b6d4;      /* Warna aksen (cyan) */
  /* ... variabel lainnya */
}
```

### Mengubah Konten
1. Edit `index.html` untuk mengubah daftar checklist
2. Ganti file di folder `files/` dengan template baru
3. Update gambar di folder `image/` sesuai kebutuhan
